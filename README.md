# Officer Elections

A [Chickadee Bandit](https://chickadeebandit.com/app-library/officer-elections) app.

Run officer elections with candidate nominations, secret ballots, majority or ranked-choice voting, and formal result certification.

## Features

- Candidate nominations.
- Secret ballots.
- Majority or ranked-choice voting.
- Formal result certification.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-officer-elections/releases/latest/download/bundle.json
```

See the [app-template](https://github.com/firebirdsystems/chickadeebandit-app-template) for build instructions and the full manifest field reference.
